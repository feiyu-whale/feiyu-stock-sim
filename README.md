# 🎮 时光机炒股 · 模拟

> 一个纯前端的「金融生存模拟」小游戏——回到过去，用虚拟资金搏杀一段被剥光信息的市场。

⚠️ **本游戏纯属娱乐：虚拟资金、历史回放数据，与真实市场无关，不构成任何投资建议。**

---

## 🐳 这是什么

一个零依赖、零联网、零存储的纯前端单页游戏。开局给你一笔虚拟资金，回到 2000 年，用「下一天 / 下一年」推进时间，在二十多年的市场里买卖、做空、借贷、避税……体验一场**被剥光了信息差**的交易人生。

**它不哄你**：没有新闻、没有研报内幕（研报要花钱买，还可能被骗）、名字全是虚构的、真身每局随机重洗。你面对的，只有一条光秃秃的 K 线。

> 能不能在这里活下来、甚至滚到顶——考的是纯纯的交易功力，不是消息。

---

## 🕹️ 玩法一览

**双市场**
- 🇨🇳 A股（21 只）· 🌍 美股（20 只，含真退市股）
- 股票数量固定，但「数据 ↔ 假名」**每局开局随机重洗**——上一局的名字，这一局对不上号

**交易**
- 买卖（A股按「手」=100股，美股按「股」）
- 🩹 **做空**：借券卖出，跌了买回赚差价
- ⚡ **梭哈**：一键把现金全部买入

**信息（都要花钱）**
- 📄 **研报**：花总资产 50%，解锁该股「行业标签 + 基本面」
- 📨 **小道消息**：花总资产 10%，**可能是真的，也可能是庄家出货的假消息**
- 🧠 **恐慌/贪婪指数**：市场情绪，贪婪见顶、恐慌抄底

**宏观与博弈**
- 🏛️ **利率事件**：加息/降息，跨年弹出，逼你看宏观周期
- 🔥 **大事件**：牛市 / 金融危机 / 疫情……沉浸式弹窗
- 💬 **股吧论坛**：NPC 散户/游资发帖（纯噪声，别当真）

**钱与风险**
- 💱 **手动换汇**：人民币 ↔ 美元，收 1% 服务费，汇率随历史变动
- 🏦 **钱庄借贷**：上限 = 净资产 ×1000%，年息分档（<100万 8% / 100万~1亿 15% / >1亿 30%），利滚利
- 📉 **融资爆仓线**：维持担保比例 <130% 强制平仓
- ☠️ **退市归零**：持有退市股 → 强制平仓、血本无归
- 💀 **破产**：资不抵债 → 游戏结束
- 💰 **税收**：卖出即按总资产套档收税（A股套中国表 / 美股套美国表），亏了也收
- 🏝️ **海外信托**：1000 万门槛，10 种离岸信托，**每年摇一次背叛判定**——中了卷款跑路

**复盘**
- 📊 年终财报（总资产 / 交易胜率 / 纳税总额）
- 📜 交易记录导出 CSV
- 🔊 音效（买卖/破产）

## 🚀 运行

**零依赖、零构建**——直接双击 `index.html`，或起个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

数据文件（`data.json` / `data.us.json` / `fx.json`）必须与 `index.html` 同目录。

## 🎯 定位

这是一个**教学向的硬核模拟**——它把炒股里所有「侥幸」的路都堵死了：
- 掐信息（名字假的、没新闻）
- 掐提示（不教你）
- 掐杠杆（蒙对了也难暴富）
- 每局重洗（连记 K 线都不好使）

**能在这套系统下活到最后的，是真本事。**
